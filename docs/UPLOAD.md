# Initial GitHub upload

Suggested repository name: bitcoin-financialization-time-preference

Suggested description: Institutional mechanisms linking Bitcoin financialization, engagement, and effective time preference. Model, results, and replication materials.

Extract the supplied ZIP. The contents of the bitcoin-financialization-time-preference folder belong at the repository root, so README.md appears on the landing page.

For browser upload, create an empty repository, choose Add file → Upload files, and upload the extracted folder contents. Include the .github and .gitignore entries. Do not upload the ZIP as the only repository file.

For Git, initialize the extracted folder, add the files, commit, and push to the newly created repository. The package includes a replication workflow that runs when files reach GitHub.

Before a formal release, add the SSRN DOI to README.md and CITATION.cff when available. No repository URL or DOI is invented in this package.
